# ASIR — Administración de Sistemas Informáticos en Red

Repositorio personal de formación y desarrollo técnico en Administración de Sistemas Informáticos en Red (ASIR).

Este espacio reúne laboratorios, ejercicios, scripts y proyectos propios, así como versiones revisadas de prácticas realizadas durante mi formación en la Universitat Oberta de Catalunya (UOC).

## Áreas de conocimiento

| Área | Contenidos |
|---|---|
| [01 — Redes](./01-redes/) | Fundamentos, IPv4/IPv6, subnetting, routing, switching y servicios de red |
| [02 — Sistemas Operativos](./02-sistemas-operativos/) | Linux, Windows, Windows Server, administración, virtualización y scripting |
| [03 — Bases de Datos](./03-bases-de-datos/) | Modelo relacional, SQL, MySQL, Oracle y administración de BBDD |
| [04 — Programación](./04-programacion/) | Fundamentos de programación, algoritmos, estructuras de datos y proyectos |
| [05 — DevOps y Cloud Computing](./05-devops-cloud/) | Git, GitHub, automatización, contenedores, CI/CD y cloud computing |
| [06 — Arquitectura y Seguridad](./06-arquitectura-seguridad/) | Arquitectura de sistemas, infraestructura, seguridad informática y hardening |

## Objetivos del repositorio

- Consolidar conocimientos de Administración de Sistemas Informáticos en Red.
- Reforzar los fundamentos mediante ejercicios y laboratorios prácticos.
- Revisar, ampliar y rehacer proyectos de mi formación académica.
- Documentar procedimientos técnicos claros y reproducibles.
- Desarrollar habilidades de administración, diagnóstico y automatización.
- Construir un portafolio técnico que refleje mi evolución profesional.

## Organización del repositorio

Cada área incorporará progresivamente fundamentos, laboratorios, prácticas académicas revisadas, proyectos personales y documentación técnica.

La estructura interna se ampliará a medida que se desarrollen nuevos contenidos.

## Metodología de trabajo

1. Estudio de los fundamentos teóricos.
2. Realización de ejercicios de comprensión.
3. Aplicación práctica mediante laboratorios.
4. Documentación de procedimientos y resultados.
5. Revisión de errores y propuestas de mejora.
6. Publicación y actualización del repositorio.

Cada proyecto relevante contará con su propio README que documente objetivos, requisitos, procedimiento, validaciones y conclusiones.

## Tecnologías y herramientas

- **Sistemas operativos:** GNU/Linux, Windows 11 y Windows Server.
- **Virtualización:** KVM/QEMU, Hyper-V y otras soluciones.
- **Redes:** TCP/IP, DNS, DHCP, VLAN y routing.
- **Bases de datos:** MySQL, Oracle y SQL.
- **Programación y scripting:** Bash, PowerShell y Python.
- **DevOps:** Git, GitHub, Docker y automatización.
- **Seguridad:** permisos, hardening, controles de acceso y análisis de configuraciones.

Estas tecnologías forman parte del plan de aprendizaje y no implican que todas tengan proyectos publicados.
